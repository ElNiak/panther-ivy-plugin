### Patch 1 — workflow-name drift (CRITICAL — but the fix is architectural, not mechanical)

**Important caveat surfaced during patch attempt:** the "rename" map I initially proposed (`workflow-triage → triage-ops`, etc.) does not work, because all four `*-ops` skills declare `user-invocable: false` in their frontmatter:

```
skills/triage-ops/SKILL.md:4   user-invocable: false
skills/verify-ops/SKILL.md:4   user-invocable: false
skills/build-ops/SKILL.md:4    user-invocable: false
skills/review-ops/SKILL.md:4   user-invocable: false
```

Their descriptions say "Operating procedure preloaded into the ivy-{role}-agent at spawn… Not user-invocable directly." So `Skill(skill="panther-ivy-plugin:triage-ops")` would fail with a *different* runtime error after the rename.
